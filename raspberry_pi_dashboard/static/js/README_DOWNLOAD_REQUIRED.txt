REQUIRED FILE MISSING: chart.min.js

This directory needs the Chart.js library to function.

Please run the download script to get the required files:

    bash raspberry_pi_dashboard/download_offline_resources.sh

Or download manually from:
    https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js

Save as: chart.min.js (in this directory)

See SETUP_OFFLINE_RESOURCES.md for detailed instructions.
