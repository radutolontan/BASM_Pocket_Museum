REQUIRED FILES MISSING: Bootstrap Icons font files

This directory needs Bootstrap Icons font files to display icons.

Required files:
    - bootstrap-icons.woff2
    - bootstrap-icons.woff

Please run the download script to get the required files:

    bash raspberry_pi_dashboard/download_offline_resources.sh

Or download manually from:
    https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.0/font/fonts/bootstrap-icons.woff2
    https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.0/font/fonts/bootstrap-icons.woff

See SETUP_OFFLINE_RESOURCES.md for detailed instructions.
