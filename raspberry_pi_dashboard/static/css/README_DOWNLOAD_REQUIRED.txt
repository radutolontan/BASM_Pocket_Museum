REQUIRED FILE MISSING: bootstrap-icons.min.css

This directory needs Bootstrap Icons CSS to display icons.

Please run the download script to get the required files:

    bash raspberry_pi_dashboard/download_offline_resources.sh

Or download manually from:
    https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.0/font/bootstrap-icons.min.css

Save as: bootstrap-icons.min.css (in this directory)

See SETUP_OFFLINE_RESOURCES.md for detailed instructions.
