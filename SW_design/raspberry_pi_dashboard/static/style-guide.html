Text Widths

Different content widths for optimal readability.

Full Width (100%)

The BASM Pocket Museum dashboard provides real-time visualization of sensor data from multiple ESP32 "Pocket Lab" devices. Students can explore scientific principles through hands-on experiments, recording their observations and answering teacher-guided questions. This full-width text spans the entire container, useful for tables, charts, and data displays that need maximum horizontal space.

Wide (80ch / ~960px)

The BASM Pocket Museum dashboard provides real-time visualization of sensor data from multiple ESP32 "Pocket Lab" devices. Students can explore scientific principles through hands-on experiments, recording their observations and answering teacher-guided questions. This width is optimal for technical content, documentation, and data-heavy interfaces.

Reading Width (70ch / ~840px)

The BASM Pocket Museum dashboard provides real-time visualization of sensor data from multiple ESP32 "Pocket Lab" devices. Students can explore scientific principles through hands-on experiments, recording their observations and answering teacher-guided questions. This is the optimal width for comfortable reading of body text in articles and content pages.

Comfortable (60ch / ~720px)

The BASM Pocket Museum dashboard provides real-time visualization of sensor data from multiple ESP32 "Pocket Lab" devices. Students can explore scientific principles through hands-on experiments. This width works well for blog posts, instructions, and narrative content.

Narrow (50ch / ~600px)

The BASM Pocket Museum dashboard provides real-time visualization of sensor data from multiple ESP32 "Pocket Lab" devices. Perfect for mobile layouts, sidebars, and focused content sections.
